# rhumbpad

**This is a placeholder package.** It exists to hold the npm name while the
project's source is finalized.

[Rhumbpad](https://rhumbpad.com) is a notepad calculator for numbers you
don't know yet — the answer column holds distributions, not single numbers.

- The app: <https://rhumbpad.com>
- Docs: <https://rhumbpad.com/docs/>
- The real npm package arrives with the open-source launch; run
  `npx rhumbpad` and you get this pointer.
